# UXC 36गढ़ — Neo Retro Pop Community Site

A text-first neo-retro-pop website for the UXC UI/UX designer community.

## Run locally

Requirements: Node.js 20+ and npm.

```sh
npm install
npm run dev
```

Open the local URL shown in the terminal (usually http://localhost:5173).

## Production build

```sh
npm run build
npm run preview
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
